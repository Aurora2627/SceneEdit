## 解释边界

开发阶段选参使用的 seed=42 未纳入本轮均值。开发新种子与独立素材分开报告；不按帧数伪造样本量，不将两个相关种子当作大量独立视频。car-turn 先前曾被查看，因此属于独立案例验证，不是盲测。

像素误差降低不等于语义保真、背景服从或时序质量提升。边界环同时包含车身与背景，作为诊断展示；远背景变化也不等于编辑成功。完整视频人工评审和更多独立素材验证仍待补。没有训练或更新基础模型权重，没有输出前景复制或合成。

模型、运行参数、逐帧结果和冻结协议均保留；本报告展示全部预定配对，不筛选有利种子。
