## 结论与可见问题

参考图效果需逐素材判断，不能用这两个案例、一个种子宣称稳定提升。car-turn 的保留区域 MAE 从 0.112433 降至 0.106875，约降低 4.94%；该数值不等于整体生成质量提升。

助手已检查两段素材的第 0、8、16 帧对照图：均生成海岸道路背景，车辆大体位置与姿态跟随输入；car-roundabout 尾部及轮廓存在变化，car-turn 车头、格栅和轮胎细节存在较明显改变。抽帧检查不能替代完整视频播放与人工评审；时序稳定性结论待补。

## 下一步

优先在开发素材上定位车身细节与边界漂移，固定种子对比控制强度和掩码边界策略；保留 car-turn，不用其反复调参。随后扩大到独立拍摄组和多个种子，再决定是否需要 VACE 控制分支 LoRA。训练需要匹配目标场景的正确监督，不能将海岸提示词与原始城市视频配成错误标签。
