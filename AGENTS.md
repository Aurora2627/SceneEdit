# Project rules
- Develop and run through Windows VS Code Remote SSH with the scenedit-cuda virtual environment.
- Use saved Python sources and PyTorch for model inference/training. Keep all source/config/input/model hashes, logs and actual results.
- Freeze revisions, retain upstream attribution and license. Never claim upstream model training as project work.
- Keep data, weights, credentials and environments outside Git. Preserve historical runs.
- Do not run SceneEdit GPU workloads while the ClipRank comparison is running. CPU preparation/download is allowed.
- Commit validated updates on main, update CHANGELOG and VERSION_HISTORY, create and push annotated version tags.
